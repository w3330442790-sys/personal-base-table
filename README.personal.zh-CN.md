# 我的多维表格

基于 Weilanx Base Table 0.18.0 的 Obsidian 个人版，插件 ID 为 `personal-base-table`。

## 使用入口

- 原有 `.wbase` 文件可以直接打开。底部统一切换和新建独立工作表，新建后自动进入新表。已有多视图设置保留在功能区右上角的筛选方案下拉框中。
- 行号列默认宽度为 56px，可拖动行号表头右侧边界调整。字段菜单、编辑栏和选区右键操作面板跟随点击位置显示。
- 单元格拖选或 Shift 扩选后右键，可以插入行、复制、粘贴、填充、清空、合并或移动到其他工作表。
- 行右键选择“设置为父节点”，指定随后 N 行或已选记录作为子行。父行左侧三角按钮控制折叠。
- 选择多列后右键创建列组，通过列组按钮折叠和展开。
- 顶部提供查找替换、条件格式与汇总、模板和历史快照。Ctrl/Cmd+F、Ctrl/Cmd+H 打开查找替换。
- 工具窗默认位于表格右上角，拖动标题栏可移动，关闭再打开保留本次位置。
- 单击选择单元格，双击或 F2 编辑，也可直接打字开始输入。Enter 确认并向下移动，Tab 向右移动，Esc 取消。长文本在单元格内编辑，Alt+Enter 换行。
- 选区右键支持增粗、斜体、下划线、删除线、对齐、清除格式及删除行列。Ctrl/Cmd+B、I、U 可设置格式，格式操作支持撤销和重做。
- 行号旁的详情按钮打开长文本、图片、附件和笔记链接。
- Ctrl/Cmd+Z 撤销，Ctrl/Cmd+Shift+Z 或 Ctrl+Y 重做。文件内所有工作表按操作顺序共享历史。

## 1.1.0 功能区

顶部按“开始、插入、数据、公式、视图、工具”分类，右侧搜索按钮可按名称查找功能。

- 开始：字体颜色、填充色、字体样式和选择性粘贴。仅内容粘贴公式的计算结果，仅格式保留目标内容，普通内部复制会平移公式相对引用。
- 数据：筛选、排序、条件格式，以及重复项高亮与去重。可选择比较字段和范围，预览后确认删除，支持撤销。
- 公式：支持 `SUM`、`AVERAGE`、`COUNTIF`、四则运算、括号和 A1 区域引用，例如 `=SUM(C1:C5)`、`=AVERAGE(C1:C5)`、`=COUNTIF(C1:C5,">0")`。支持 `$A$1` 绝对引用，仅计算当前工作表，不支持跨工作表公式。编辑栏显示原公式，单元格显示结果。
- 视图：自动列宽、自动行高、指定行与列冻结。也可双击列右边界或行号下边界适应内容，拖动边界手工调整。冻结行按记录保存，在当前视图固定到表头下方。
- 插入与工具：新增行列、工作表、父子节点、模板、详情、历史快照及导出。

## 安卓平板与触屏（1.1.1）

- 点按选中单元格，用“编辑选中”进入输入；电脑仍可双击或 F2 编辑。
- 开启“范围选择”，先点起点，再点终点，即可选择矩形区域。“选区操作”提供完整菜单，也可原地长按约半秒打开。滑动、第二根手指和系统取消会取消长按。
- 手指滑动表格用于滚动。行列边界支持触屏拖动，自动尺寸也可从“视图”使用；触屏填充使用“填充区域”按钮。
- 功能区可收起，按钮使用更大点击区域，支持横竖屏。软键盘弹出后压缩功能区并调整表格、菜单及工具窗的可见高度。
- 系统拒绝剪贴板权限时，同一插件会话仍可用按钮复制粘贴内部区域；跨应用粘贴可在“粘贴预览”输入框使用安卓系统粘贴。
- 桌面行移动从行号区拖动，单元格拖选不再触发行移动。优化大表层级整理和选择时重复计算。

已做浏览器安卓触屏模拟、横竖屏与键盘视口模拟验证。尚未在安卓平板真机测试，系统键盘和厂商 WebView 的实际表现仍需真机确认。

## 紧凑功能区与滚动（1.2.0）

- 顶部改为 Excel 式简化功能区：标签栏、单行图标命令和编辑栏。桌面顶部高度从约 175px 降到约 110px，平板从约 227px 降到约 133px。
- 命令按分组用细线分隔，鼠标悬停显示完整名称；标签右侧的搜索按钮展开功能搜索，“⋯”打开当前分类的全部命令；功能区可收起并记住状态，收起时点击标签即展开。
- 保存状态移到工作表标签栏右侧；选区大小、列组和“序列填充”开关移到表格底部状态栏。
- 表格成为唯一滚动区域，表头吸顶、行号列固定：鼠标滚轮上下滚动，Shift + 滚轮左右滚动，触控板横向滑动直接左右移动；平板单指滑动带惯性。

## 渲染修复（1.2.1）

- 修复编辑列名后表格内容区整体消失：改名提交后、文件写回前会短暂拿不到新列定义，现在按文本列兜底渲染，改名立即生效。
- 内容区增加渲染错误兜底，异常时显示提示和“尝试重新渲染”，不再整页空白；数据与文件不受影响。

## 1.3.0 排序、导入与安全保存

- 点击列头名称在升序、降序和取消排序之间切换；列头右侧 `▾` 仍打开字段菜单。多列排序继续在“排序”面板中设置，空值始终排在末尾。
- “数据 → 导入”可从 CSV/TSV 文件或粘贴文本新建工作表，自动识别分隔符、首行字段名和数字/日期/复选类型，导入前显示预览。
- 导出增加 Markdown 表格，适合直接粘贴进笔记；Markdown 导出使用当前视图的可见列和筛选结果。
- 命令面板新增“快速新增记录”：当前表格直接新增；没有打开表格时，从库内 `.wbase` 中选择一张表后新增。
- 首次写入前自动备份到库内 `.personal-base-table-backups`，可在设置关闭；备份失败会停止保存，避免不可逆覆盖。
- 查找结果现在会切换到对应工作表、选中单元格并滚动定位；结果被筛选、折叠或隐藏列挡住时会明确提示。
- 文档结构错误、损坏快照和保存失败草稿都有对应的失败关闭/恢复路径。

## 数据与恢复

主工作表继续保存于原来的 `fields`、`views` 和 `records`。新增工作表保存于 `personal` 扩展数据，层级、合并和条件格式保存于 `personalGrid`。

删除列、批量替换、粘贴、删除、合并和恢复前会生成快照。历史目录为库内 `.personal-base-table-history`。默认每文件保留 30 份，容量上限 100 MB，可在插件设置调整。手动快照同样支持关闭文件后恢复。自动备份位于 `.personal-base-table-backups`，默认每次打开或外部更新后的首次保存前生成，可在设置关闭。

保存失败时会把待保存内容保留在本机存储，关闭后重新打开文件仍可恢复；可以重试保存、导出独立副本或放弃，重试成功或放弃后清除。检测到外部修改时重置失效的会话撤销历史，持久快照继续保留。

带有个人版扩展的文件请继续使用个人版编辑。原版保存文件时会忽略个人版的附加工作表和扩展数据。

## 安装

将安装包中的 `main.js`、`manifest.json` 和 `styles.css` 放入库的 `.obsidian/plugins/personal-base-table`。

关闭原来的 Weilanx Base Table，再开启“我的多维表格”，使 `.wbase` 文件由个人版打开。原插件目录可保留用于回退。

## 当前边界

- 拖动填充向下扩展，序列模式将数字加一或日期递增一天。
- 查找替换遇到合并区域会列出冲突，取消合并后可替换。纵向合并涉及排序时会提示先拆分再继续。
- CSV 导出普通单元格，Excel HTML `.xls` 导出支持合并区域，完整 JSON 导出包含全部工作表。
- 链接字段只有 `http`、`https`、`mailto` 会显示为可点击链接，其他协议按文本显示。
- 笔记改名会更新裸链接和完整路径链接；同名笔记存在时只更新完整路径链接，避免误改。
- 历史差异每张表显示前 100 项，并显示全部差异数量。
